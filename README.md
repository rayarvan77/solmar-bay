Solmar Bay is an original open-world crime game built with three.js — a procedural sun-soaked coastal city you explore on foot and by car. Cruise the streets, steal cars, dodge traffic and pedestrians, outrun the police as your wanted level rises, fight back, and work your way through a 5-mission story as Dana Vega, a courier pulled into the underworld. It has a full HUD with minimap, cash rewards, save progress via localStorage, and WebAudio-synthesized sound — no audio files needed.

## Run it

```bash
node serve.ts
```

Then open http://localhost:8080 in your browser.

Alternatively, serve `game/index.html` with any static file server.

## Controls

| Key | Action |
| --- | --- |
| WASD | Move |
| Mouse | Look around |
| Shift | Run |
| Space | Jump |
| E | Enter / exit / steal car |
| Mouse click | Punch / shoot |
| R | Reload |

## Missions

Play as Dana Vega, courier of Solmar Bay, through five story missions:

1. **Hot Wheels** — Steal any car and drive it to the Docks. (+$500)
2. **Express Run** — Deliver a package to the Northside penthouse in 100 seconds. (+$800)
3. **Cool Down** — Get the heat up to 2 wanted stars, then shake it off completely. (+$600)
4. **Dockside Brawl** — Defeat Rico's 4 enforcers at the Docks. (+$1,000)
5. **The Big Score** — Reach the Old Airport with at least 2 wanted stars — with the whole Bay PD on you. (+$2,000)
